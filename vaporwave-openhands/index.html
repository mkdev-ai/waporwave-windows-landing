WHAT CAN OPENHANDS DO?

An open-source AI agent that does real software engineering work, inside its own sandboxed computer:

  • Browses the web for docs, research & dependencies
  • Fixes GitHub issues end-to-end and opens the pull request
  • Plans big tasks, decomposes them, and verifies its own work
  • Extends itself with custom tools & MCP integrations
